# Reproduction files

This repository contains only the code and fixed toolchain files needed to reproduce the paper's formal and exact computational checks.

- `LeanBP/TestProj/` contains the cited Lean files, `lakefile.toml`, `lake-manifest.json`, and `lean-toolchain`.
- `domino_max/` contains the selected exact Python verification scripts.
- `requirements.txt` pins the Python dependency.

The paper PDF, LaTeX source, author metadata, research notes, logs, backups, and private workspace files are intentionally excluded.
